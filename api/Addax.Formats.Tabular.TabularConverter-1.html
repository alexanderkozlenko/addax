TryFormat(T?, Span<char>, IFormatProvider?, out int)

When overridden in a derived class, tries to format a value into the provided span of characters.

public virtual bool TryFormat(T? value, Span<char> destination, IFormatProvider? provider, out int charsWritten)

Parameters

value T

The value to format.

destination Span<char>

The span in which to write the value formatted as a span of characters.

provider IFormatProvider

An optional object that supplies culture-specific formatting information for destination.

charsWritten int

When this method returns, contains the number of characters that were written in destination.

Returns

bool

true if the formatting was successful; otherwise, false.

Remarks

The method should return false only if there is not enough space in the destination buffer. Any other failures should throw an exception. The default implementation throws a NotSupportedException.
