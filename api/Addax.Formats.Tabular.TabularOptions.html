BufferSize

Gets or sets the minimum size of the buffer in bytes for reading from and writing to a stream.

public int BufferSize { get; set; }

Property Value

int

A 32-bit signed integer. A value less than one is treated as one, and a value greater than MaxLength as MaxLength. The default is 16384.

Converters

Gets the value converters that readers and writers created with these options use instead of the converters in Converters.

public IDictionary<Type, TabularConverter> Converters { get; }

Property Value

IDictionary<Type, TabularConverter>

A dictionary with a type as the key and a converter for values of that type as the value. The default is an empty dictionary.

Encoding

Gets or sets the character encoding for reading from and writing to a stream.

public Encoding? Encoding { get; set; }

Property Value

Encoding

An Encoding instance or null to use UTF-8 encoding, which skips a byte order mark (BOM) when reading and writes none. The default is null.

FormatProvider

Gets or sets the object that supplies culture-specific formatting information when reading and writing fields as typed values.

public IFormatProvider? FormatProvider { get; set; }

Property Value

IFormatProvider

An IFormatProvider object or null to use the default culture-independent provider. The default is null.

public IDictionary<Type, TabularHandler> Handlers { get; }

Property Value

IDictionary<Type, TabularHandler>

A dictionary with a record type as the key and a record handler for that type as the value. The default is an empty dictionary.

TabularStringFactory
